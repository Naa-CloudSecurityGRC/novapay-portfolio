# Stakeholder Interviews & Gap Analysis: SOX Evidence Collection

**Skills shown:** elicitation, interview design, synthesis into themes, gap analysis, writing a recommendation for decision-makers.

## Case study

| | |
|---|---|
| **Why I built this** | Elicitation is the core BA skill, and SOX evidence collection is a process I know well from the inside. |
| **Explain** | Interviews with control owners about evidence requests, turned into a gap analysis and a pilot recommendation. |
| **What was broken** | Unclear evidence expectations, requests bunched after quarter end, duplicate asks from internal and external audit. |
| **What was fixed** | Recommended evidence cards, a shared testing calendar, one request list with external audit, Jira as the submission channel. |
| **Business impact** | Fewer returned requests and less evidence work during close (to be measured in a 90-day pilot). |
| **Remediation still open** | Validate findings with interviewees; approve pilot scope. |
| **Decisions and trade-offs** | I recommended a 90-day pilot for 28 controls rather than a big-bang change, so results can be measured first. |

## Details

| File | What it is |
|---|---|
| [interview_guide.md](interview_guide.md) | 30-minute semi-structured interview guide with note-taking template |
| [gap_analysis.md](gap_analysis.md) | Findings from 3 (simulated) interviews, current vs. desired state, and a one-page pilot recommendation |

**Headline:** control owners lose most time on unclear evidence expectations and requests clustered after quarter end. Recommended a 90-day pilot: evidence cards, a shared testing calendar, one request list with external audit, Jira as the submission channel, and saved IPE reports.
