# GRC Analyst Projects

| # | Project | Key artifacts |
|---|---|---|
| 1 | [SOC 2 Readiness Assessment](01-soc2-readiness/) | 36 Security + Availability criteria assessed (71% ready), 90-day plan |
| 2 | [Policy Pack](02-policy-pack/) | 5 policies: Information Security, Acceptable Use, Access Control, Incident Response, Data Retention |
| 3 | [ITGC Control Testing Workpapers](03-itgc-control-testing/) | 5 controls tested, 83 items, 1 deficiency with full evaluation memo |
| 4 | [Framework Crosswalk](04-framework-crosswalk/) | 30 controls mapped to NIST CSF 2.0, ISO 27001:2022, SOC 2, PCI DSS v4.0 |

The projects connect: the readiness assessment finds the gaps, the policy pack closes the policy gap (CC5.3), the workpapers test the access and change controls, and the crosswalk shows how one set of evidence serves every framework.
