# Field Guide: Deficiency, Significant Deficiency, or Material Weakness?

## Case study

| | |
|---|---|
| **Why I built this** | Classifying deficiencies is where SOX judgment shows. I wanted a short guide I could walk an interviewer through. |
| **Explain** | It explains the three levels (deficiency, significant deficiency, material weakness) and the checks that change the answer. |
| **What was broken** | Teams often classify on the error found rather than what could happen, and skip aggregation and compensating controls. |
| **What was fixed** | A simple decision path: likelihood x magnitude, then compensating controls, aggregation, root cause and the prudent official test. |
| **Business impact** | More consistent, defensible conclusions for auditors and the Audit Committee. |
| **Remediation still open** | Add worked examples from the NovaPay deficiency log. |
| **Decisions and trade-offs** | I kept it to six slides; a long policy would not get read by control owners. |

## Details

A 6-slide guide to evaluating SOX control exceptions under PCAOB AS 2201: definitions, likelihood x magnitude, compensating controls, aggregation, root cause, the prudent official test, and indicators of a material weakness (AS 2201.69).

See `carousel_deficiency_evaluation.pdf`.
